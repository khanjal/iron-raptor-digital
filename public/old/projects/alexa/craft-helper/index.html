Craft Helper

Published November 26, 2017 · Last updated November 26, 2017

Craft Helper is an unofficial Minecraft assistant that helps you find information without having to browse or search for it. Simply ask it your question based on the examples below and it will do it’s best to find that information for you. If there is any information missing or should be added please let us know. We are constantly adding synonyms for crafting items.

 

Here are a some examples of commands you can say (start with “Alexa, ask craft helper…”):

 

Build

“… build end portal”

“… how do I build a snowman”

“… how do I build an iron golem”

“… how do I build nether portal”

 

Breed

“… breed horses”

“… how do you breed pigs”

“… how do I breed a cow”

“… how to breed two sheep”

 

Craft

“… craft bed”

“… how do you craft a diamond sword”

“… how do I craft cookies”

“… how to craft a furnace”

 

Random

“… random”

“… tell me a random recipe”

“… what is a random recipe”

“… give me a random recipe”

 

Smelt

“… smelt oak wood”

“… what happens when I smelt iron ingot”

“… what does smelting cactus produce”

“… how do I smelt iron ore”

 

Tame

“… tame ocelot”

“… how do you tame horses”

“… how do I tame a parrot”

“… how to tame wolves”

 

Change Log

 

August 27, 2017

  • Red flower, yellow flower, and double plant data values now translate.
  • If you don’t say an item to smelt, you will be suggested a random one.
  • If you don’t say something to build, you will be suggested a random one.
  • Random will now include smelting recipes and building information.

 

August 20, 2017

  • Quicker intents added to the examples above.
  • If you don’t say an item to craft, you will be suggested a random one.
  • Crafting will check building and then smelting if the previous recipe is not found.
  • Building will check crafting and then smelting if the previous recipe is not found.
  • Smelting will check crafting and then building if the previous recipe is not found.

 

August 5, 2017

  • Added UK language support.
  • Asking about building will check crafting.
  • You can now ask alexa to repeat what was just said.
  • Smelting recipes added.
  • If crafting recipe not found, it will check smelting.

 

July 25, 2017

  • Updated skill to use slot synonyms.
  • Wired up items.json file which will hold brewing, smelting, crafting recipes, where items are found, and how items are used.
  • Restructured files and separated out repeated code into helpers.
  • Misc fixes for items like villager breeding info and log type references.

 

July 16, 2017

  • Updated the way rows and columns are referenced.
  • Added what materials and quantity you need before the recipe is read.
  • Added an ask emit so you don’t have to say “ask craft helper blah blah blah” each time.
  • Added random intent so you can just hear a random recipe.
  • Allowed this skill to be used in all countries but still restricted to en-US language.
