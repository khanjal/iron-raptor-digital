# Archive

Backups kept in the repository for safety. Nothing in this folder is published;
only `public/` and the Angular build are deployed.

- `wordpress-2026-11-02/` — the old WordPress site at www.ironraptordigital.com,
  captured before the move to this site. `pages/` holds each page as it was served,
  `content/` the clean page content from the WordPress REST API, `images/` the uploads,
  and `index.md` lists everything with its original URL.

A browsable copy built from that content is published at `/old/` (see `public/old/`).
